# NyayaFlow ⚖️
An AI-orchestrated legal workflow engine for Indian MSMEs. 

## Tech Stack
- **Frontend:** React, TypeScript, Vite
- **Backend:** Node.js, Express, TypeScript
- **Infrastructure:** Docker, Docker Compose
- **AI:** Gemini Flash 1.5, Vector RAG (Coming Soon)

## How to Run
```bash
docker compose up --build
